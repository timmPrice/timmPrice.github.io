# blog (zenroutes)

Static personal site. No build step — plain HTML/CSS/JS.

## Layout
- `index.html` + `styles/main.css` + `src/lm-toggle.js` — hand-written home page.
- `pages/posts.html` — posts index (exported from Obsidian).
- `posts/*.html` — individual posts (exported from Obsidian).
- `styles/post.css` — shared styling for every exported page. Edit here; no re-export needed.
- `obsidian-plugin/export-to-html-custom/` — modified fork of kalvn's "Export to HTML"
  plugin. Symlinked into `~/obs-notes/.obsidian/plugins/` (the vault gitignores `.obsidian/`),
  so it is versioned here. User must reload the plugin in Obsidian after edits.

## Writing / exporting
- Source notes live in `~/obs-notes/post/` and are named `<name>.html.md`, so the plugin's
  download (note basename) comes out as `<name>.html`.
- Template: `~/obs-notes/post/_post-template.md`.
- Export is manual in Obsidian (Ctrl+P → "Download as an HTML file"); Claude can't run it.
  Posts → `posts/`, `posts.html.md` → `pages/`. Links are relative (`../pages/posts.html`,
  `../index.html`), so both folders work.
- The plugin inlines images as base64 data URIs (jpg/png/bmp/webp/gif/svg/avif).

## Note structure that post.css relies on (positional, plain markdown)
```
# Title
## optional subtitle
date line
[[../pages/posts.html| ⮘ back ]] :LiActivity:  [[../index.html|home ⮚]]   ← line right above first --- = nav
---
body
---
[[../index.html|~]]/[[../pages/posts.html|posts]]/post_name                ← after a ---, starts with ~ link = terminal-prompt footer
```
- Everything above the first `<hr>` is the centered header.
- The "Exported directly from my Obsidian vault." footnote is generated by CSS.
- Don't use inline HTML (e.g. `<span class=…>`) as hooks in notes: Obsidian won't render
  wikilinks inside HTML, and `.prompt` collides with Obsidian's own UI class.

## Git / deploy
- `origin` (timmPrice/blog) = backup only, not served.
- `deploy` (timmPrice/timmPrice.github.io) = the LIVE site at timmprice.github.io.
  Deploy is `git push deploy master --force` — only when the user explicitly asks;
  pushing to origin is fine for backups.
